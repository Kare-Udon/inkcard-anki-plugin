# InkCards Anki 插件

在 Anki Desktop 与[阅星曈 X4](https://www.xteink.cn/) 设备之间同步图文卡片与复习记录。

当前版本：`0.2.0-preview.20`，配套 **InkCards 设备端 `0.2.76`（API 2.6）**。插件与设备分别编号。

本包的图像转换组件为 macOS Apple Silicon / CPython 3.13 构建；Windows、Linux、Intel Mac 或其他 Python ABI 的图像功能未经验证。支持范围中的 Anki 版本仍须满足该运行环境。

当前为预发布版本。设备端真机仍有 `descriptor json_encode` 同步失败待定位；0.2.76 增加诊断，并未宣称修复。API 0.8 旧版设备的卡库和未回传评分不会自动迁移到新文件存储，应先回传评分并完成迁移验证后升级。

支持 Anki：`26.08.1`、`26.9.3`。

插件诊断日志默认级别为“警告及错误”，系统控制台输出默认关闭。可在 InkCards 工具窗口即时调整；日志保存在当前 profile 的 `diagnostics/plugin.jsonl`，最多 128 KiB 并保留一份轮转备份。关闭日志不会禁用评分、同步收据或恢复 ledger。

## 安装步骤

1. 从 [Releases](https://github.com/Kare-Udon/inkcard-anki-plugin/releases) 下载 `.ankiaddon` 安装包。
2. 在 Anki 中打开「工具 → 插件 → 从文件安装」，选择安装包，然后重启 Anki。
3. 打开要同步的用户配置，进入「工具 → InkCards…」。
4. 按下方「局域网访问」设置电脑与 X4 的连接。
5. 在插件的「设备管理」中添加设备并输入名称，将显示的一次性固定配对码输入 X4 完成配对。
6. 在 X4 上点击「同步」即可，插件会自动检查并准备数据。同步时保持 Anki 和目标用户配置处于打开状态；插件窗口可以关闭。

## 牌组同步

首页默认列出全部牌组，新增牌组自动参与同步。只需勾选右侧「排除」列来停止同步某个牌组；排除父牌组也会排除其当前和以后新增的子牌组。排除项按牌组 ID 保存，改名不会丢失；同一 Anki 用户配置下的设备共用此设置。

排除设置自动保存，下次同步生效；正在进行的同步使用启动时的范围。保存失败会恢复旧值，配置损坏会阻断同步。搜索和「只看已排除」只改变显示，不改变同步范围。父牌组卡数包含子牌组，不能将父子行相加作为总卡数。

设备发起同步后，插件先确认旧复习记录写回，再准备当前范围并传输变化文件。排除只影响设备副本，Anki 原卡片保留；只有同步成功提交后才替换设备卡库，失败或取消保留原库。全部排除时同步为空库。容量或不支持的内容会明确阻断，需要处理原因或排除对应牌组，不能把缺少内容的结果当作完整同步。

设备管理位于顶部入口，局域网、日志和恢复选项收在设置中。主界面不再要求手动预检、准备快照或生成包。

## 设备管理

「设备管理」列表显示设备名称、待绑定/已绑定/允许重绑状态和最近连接时间。已移除设备默认隐藏，可勾选「显示已移除」查看。添加设备时填写一个名称，插件会返回 12 位固定配对码，并按 `4-4-4` 分组显示。固定码不会自动过期；创建或手动重置时只显示这一次，请当场保存。遗失后可选中设备并重置配对码。

设备名额绑定后，另一台设备不能直接占用。需要更换设备时，先选中名额并点击「允许重新绑定」，再用该名额的配对码在新设备上配对。重置配对码会让旧码和未完成的配对尝试失效，不会断开当前已绑定设备。移除设备会撤销其连接凭据和会话，但保留既有同步与评分历史。设备管理操作只在 Anki 本机界面提供。

## 局域网访问

1. 将电脑与 X4 连接到同一局域网，在电脑的系统网络设置中查看局域网 IP，例如 `192.168.1.10`。
2. 在「工具 → InkCards… → 设置」中勾选「允许局域网设备连接」。插件会将监听地址从 `127.0.0.1` 改为 `0.0.0.0`，允许通过电脑的局域网地址连接；重启 Anki 后生效。
3. 在系统防火墙中允许来自局域网的 Anki TCP `8766` 入站连接。
4. 在 X4 的「电脑地址」中填写电脑的实际局域网 IP 和端口，例如 `192.168.1.10:8766`。

也可以在「工具 → 插件」中选中 InkCards，打开「配置」，手动设置：

```json
{
  "device_server": {
    "host": "0.0.0.0",
    "port": 8766
  }
}
```

若要只监听某张网卡，将 `host` 填为电脑该网卡的实际局域网 IP，例如 `192.168.1.10`。保存配置后重启 Anki。

## 插件日志

日志默认级别为“警告及错误”，系统控制台输出默认关闭。在 InkCards 的「设置」中可以即时选择关闭、仅错误、警告及错误、常规或详细，并单独切换控制台输出。设置写入 Anki 插件配置；保存失败时界面恢复旧值。

当前 profile 的统一 JSONL 位于 `diagnostics/plugin.jsonl`，文件上限 128 KiB，另保留一份轮转备份。HTTP 成功请求记录为 info，拒绝请求记录为 warn，服务器错误和异常记录为 error；debug 增加固定阶段和脱敏调用位置。

日志不包含 Authorization、token、配对码、请求体、卡片内容、profile/device/session ID、原始 URL/query 或异常原文。关闭日志不会关闭评分、同步收据或恢复 ledger 等业务持久化。

## 开发

开发环境：Python 3.10+，以及上述支持版本的 Anki Desktop。

在源码根目录构建安装包：

```sh
python3 tools/package_ankiaddon.py
```

产物：`dist/InkCards-Anki-Bridge-0.2.0-preview.20.ankiaddon`。将其安装到 Anki，重启并打开目标用户配置，即可通过「工具 → InkCards…」启动界面。修改源码后重新构建、安装并重启。

运行打包、配对认证、存储和插件界面测试：

```sh
PYTHONPATH=. python3 -m unittest tests.test_package_ankiaddon tests.test_device_auth tests.test_storage tests.test_plugin_ui tests.test_ui_presenter tests.test_ui_device_management tests.test_runtime_device_management -v
```
